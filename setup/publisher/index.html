Connect app publishing.

Do this once. Future template setups will create their Firestore catalogue entries before deployment, using your Firebase account.

Sign in with the account that should own your app entries.

  1. Sign in above and copy your publishing credential.
  2. Open this repository’s Actions secrets.
  3. Create the secret FIREBASE_REFRESH_TOKEN and paste the credential there.

Treat this as an account credential. Keep it in Actions secrets; never put it in code, app metadata, or chat. This is shared by the central registration workflow—new apps need no separate Firebase secret.

Setup uses npm run setup:app. Ownership is derived from the signed-in Firebase account. Firestore rules stay unchanged.
